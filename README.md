A big content expansion mod adding over 140 Jokers, an exotic suit, new consumable types, challenges with actual rewards, a new side mode and a lot more.



# Content

* Over 140 new Jokers
* Brights: a new suit that counts as all base suits
* Three new consumable types: Elemental, Cups and Prestige cards
* New enhancements, editions, decks, vouchers and tags
* Challenges that unlock special jokers when beaten
* Bejeweled Mode: pick a Bejeweled Deck to play a completely new match-3 mode
